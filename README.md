# 明辨风云 · 尽责护航

航空气象课程思政互动课堂，面向飞行技术专业，围绕低能见度进近与2010年8月24日伊春案例，在“辨、明、估、定”中练习有依据的安全判断。

## 使用
- 互动课堂：https://amberx-stack.github.io/aviation-weather-classroom/
- 二维码分享页：https://amberx-stack.github.io/aviation-weather-classroom/share.html
- 约14分钟；每台设备独立保存进度，不汇总班级答题。

## 修改与发布
主界面：index.html；视觉样式：style.css；情景与判断逻辑：app.js；分享界面：share.html / share.js。
GitHub Pages设置为从main分支根目录自动发布，提交后由GitHub构建并更新。二维码已指向本仓库的Pages网址。

## 教学边界
历史案例依据最终事故调查报告，报文及RVR迁移练习为明确标注的教学设定。来源见站内“资料来源与情景说明”。实际运行以现行规章、批准的手册和航图为准。

## 已完成验证
课堂14个选项分支、分享逻辑、刷新与重置检查通过；二维码已独立解码核对。

## 学生界面与教师展示
普通课堂链接及二维码默认进入学生界面，不显示教师指引；复盘末尾可以重新练习。
教师展示链接：https://amberx-stack.github.io/aviation-weather-classroom/?view=teacher
教师模式显示教师指引，并使用独立的浏览器进度记录。扫码分享始终使用不带教师参数的学生链接。
这是界面展示模式区分，不是基于账号的访问控制。
